# pfa-Research-Project-1
Arabian Runner
For my research project, I wanted to create a game inspired by Temple Run and Subway Surfers but with an Arabian theme. I wanted to include environments inspired by Arabiandeserts and mythology. The  main idea behind the game is having a Jinn chase the player while they try to escape by avoiding obstacles and collecting coins.
I ended up sticking to my main idea and creating a playable endless runner where the player has to escape from a Jinn.

Some of the features I added include:

The player has to hold down the W key to keep running.
A Jinn follows the player from behind and gets closer if they stop running.
The player has three bone-shaped health indicators instead of regular hearts.
There are different traps and obstacles that the player has to jump over or slide under.
Coins are scattered throughout the game, and the player needs to collect 20 coins every 400 metres to survive.
The game gets harder as the player progresses, with faster gameplay and more obstacles.

3. How to Run It
Open the project in Unreal Engine.
Open the main game level.
Click inside the game viewport.
Press Enter to start or resume the game.
Hold W to keep running.
While playing, you have to avoid the traps, jump over obstacles, slide when needed, and collect coins without letting the Jinn catch you.

The game currently runs through the Unreal Engine editor. I haven't finished packaging it as a standalone game yet.
